## 一、千门八将的原始语境（骗术）

### 定义
- 「千门」是民间传说「江湖八大奇门」之一，专门指**骗术一门**。
- 「千」即「骗」的隐语：千术 = 骗术，老千 = 骗子。
- 千门八将 = 组团做局骗钱的八种角色分工，类似今天「杀猪盘」的古代原型。

### 八将分工（原始含义）
| 将 | 原始角色 |
|---|---|
| 风将 | 打探目标情报 |
| 提将 | 军师，策划整个局 |
| 谣将 | 放风造势，散布消息引目标注意 |
| 反将 | 托/诱饵，唱反调演对手戏，引目标上钩 |
| 正将 | 老千，正面出手执行、赢走钱 |
| 脱将 | 事成后安排脱身、跑路 |
| 火将 | 打手，出事时施压、护人 |
| 除将 | 善后，擦屁股、摆平麻烦、转移视线 |

### 民间衍生
- 「108 局：天局 36、地局 72」的说法（民间传说，经《千王之王》、TVB 剧、网络小说等演绎放大）。
- 其中流传的「局名」（如三仙献鼎局、雕弓天狼局、赤木疑心局等）本质是**骗局脚本的命名**。

> ⚠️ **本项目只借用「八将分工」的抽象结构，绝不照搬任何骗术手法或局名脚本。** 民间「局名」仅说明这套文化的历史存在，不纳入 Skill 的方法论。

## 二、现代商业转义（营销/布局）

- 网易号/人人都是产品经理《商业炒作的基本套路：正提反脱，风火除谣》（弦发泽，2021）将八将对应到商业炒作/事件营销：
  - 正将 = 炒作主体，提将 = 策划，反将 = 槽点/诱饵，脱将 = 权威背书，风将 = 市场洞察，火将 = 水军公关，除将 = 转移注意力，谣将 = 媒体造势。
  - 原文结论：「营销有边界，人性会越界……营销是把刀，关键是看拿在好人手里，还是坏人手里。」
- 该文同时明确指出千门八将「是江湖骗术的一种，组团作案……类似于现在的杀猪盘」。

> 本项目在此转义基础上**进一步做了合规改造**：把「水军公关」改为「真实口碑传播」，把「转移注意力」改为「危机善后」，并增加「破局防御」维度。
