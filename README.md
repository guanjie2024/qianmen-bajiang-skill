# 千门八将.skill · 商业做局与破局

> **「局」是中性词。坏人用它骗人，好人用它成事。**
> 这个 Skill 把古代「千门八将」的八种角色，翻译成现代商业的八种合法职能，帮你**做局**（设计生意）、**入局**（进入市场）、**破局**（识别并防御欺诈）。

输入一个「想法 / 产品 / 项目」，输出：
1. **做局路径** —— 八将分工闭环（情报→策划→传播→对立检验→执行→增长→留存→风控）
2. **入局路径** —— 怎么进市场：切入点 / 第一步动作 / 验证节点 / 里程碑
3. **破局与风险自查** —— 防御视角：别人怎么割你 / 你的红线 / 最可能翻车点

- 格式：遵循 AgentSkills 规范（`SKILL.md` + YAML frontmatter），兼容 Claude Code / Cursor / OpenClaw 等平台
- 定位：合法、正派、可落地的商业战略框架

## 一、千门八将是什么（诚实说明）

**原始语境：江湖骗术。** 「千门」是民间传说「江湖八大奇门」之一，专指骗术一门（"千"＝骗，"老千"＝骗子）。「八将」是组团做局骗钱的八种角色分工，类似今天「杀猪盘」的古代原型：

| 将 | 原始角色 | 将 | 原始角色 |
|---|---|---|---|
| 风将 | 打探情报 | 正将 | 老千，正面执行 |
| 提将 | 军师策划 | 火将 | 打手施压 |
| 谣将 | 放风造势 | 除将 | 善后擦屁股 |
| 反将 | 托/诱饵 | 脱将 | 跑路脱身 |

**本项目只借它的「分工思维」，绝不复刻骗术。** 我们把八个角色翻译成合法的商业职能，并增加「破局」防御维度，让它既能攻也能守。

## 二、八将 → 现代商业职能（合法版）

| 将 | 现代职能 | 将 | 现代职能 |
|---|---|---|---|
| **风将** | 市场调研 / 用户洞察 / 竞品情报 | **正将** | 产品与核心价值 / 执行落地 |
| **提将** | 战略策划 / 商业模式 / 定位 | **火将** | 销售 / 增长 / 渠道推动 |
| **谣将** | 品牌传播 / 内容营销 / 口碑 | **除将** | 客服 / 危机公关 / 留存 |
| **反将** | 竞品视角 / 红队检验 / 差异化 | **脱将** | 风控 / 退出机制 / 止损 |

**做局闭环**：`风(情报) → 提(策划) → 谣(造势) → 反(对立检验) → 正(执行) → 火(增长) → 除(留存) → 脱(风控)`

## 三、红线（不可越界）

- ❌ 不输出欺诈、骗术、诈骗手法（杀猪盘、仙人跳、老千作弊等）
- ❌ 不输出水军洗白、造谣传谣、恶意诋毁、虚假宣传、刷量
- ❌ 不输出价格操纵、垄断、侵害消费者、制造焦虑式营销
- ❌ 不输出逃债、卷款、坑用户/投资人/供应商/员工的方案

遇到「怎么骗人 / 怎么割韭菜」类请求，Skill 会**拒绝并转成破局视角**：告诉你为什么危险、别人会怎么坑你、如何防御。

## 四、安装与使用

### 方式 A：Claude Code 等支持 AgentSkills 的平台

```bash
npx skills add guanjie2024/qianmen-bajiang-skill
```

### 方式 B：手动安装

把 `SKILL.md` 放到你 Agent 平台的 skills 目录（如 Claude Code 的 `.claude/skills/qianmen-bajiang/`）。

### 触发示例

```
> 我想做一个指纹水杯，帮我布局一下
> 这个加盟项目靠不靠谱？是不是割韭菜？
> 怎么进入宠物食品这个市场？
> 帮我看看这个「稳赚不赔」的理财是不是骗局
```
